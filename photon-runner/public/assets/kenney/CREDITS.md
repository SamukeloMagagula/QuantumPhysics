# Kenney asset packs

All packs in this folder are by Kenney (https://kenney.nl) and released under
Creative Commons Zero (CC0): free to use in any project, commercial included,
with no attribution required. Credit is given here anyway.

| Folder | Pack | Source |
|---|---|---|
| `interface-sounds/` | Interface Sounds 1.0 | https://kenney.nl/assets/interface-sounds |
| `digital-audio/` | Digital Audio | https://kenney.nl/assets/digital-audio |
| `sci-fi-sounds/` | Sci-fi Sounds | https://kenney.nl/assets/sci-fi-sounds |
| `impact-sounds/` | Impact Sounds | https://kenney.nl/assets/impact-sounds |
| `ui-pack-sci-fi/` | UI Pack (Sci-Fi) | https://kenney.nl/assets/ui-pack-sci-fi |
| `game-icons/` | Game Icons | https://kenney.nl/assets/game-icons |

Downloaded 2026-11-01. Only media and license files were kept (shortcut,
`.ini` and Illustrator source files were left out). Each pack's original
license file is in its folder.

The sounds the game plays (listed in `src/sound.ts`) also have `.mp3`
copies beside the original `.ogg` files, converted with ffmpeg (LAME,
VBR quality 5) for browsers without Ogg Vorbis support such as older
Safari. Same CC0 license.
