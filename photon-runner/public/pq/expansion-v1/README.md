# Map expansion artwork

Created with the built-in image generation tool. Style was guided by inspection of the existing quantum wing, engineering workshop and headquarters images.

Open [the gallery](index.html) to browse all eight PNGs. Four room backgrounds are 1536 x 1024; four props use transparent backgrounds. All eight are integrated into the game with walkable floors, reciprocal doors, interactive consoles and collidable, depth-sorted props. The power room uses its rear door for entry and exit.

Routes (access card required): Communications Centre → Server Hall; Quantum Wing → Cryogenics Lab; Cryptography Lab → Secure Archive; Engineering Workshop → Power Control Room. All four also appear in the room tour. Room and prop definitions live in `src/pqExpansionRooms.ts`.
